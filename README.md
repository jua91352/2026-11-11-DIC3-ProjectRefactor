# FMPA — Fresh Market Price Forecast Agent

> 結合大型語言模型（LLM）、領域知識與價格資料分析的農產品價格預測代理系統。

## 專題簡介

本研究提出 **Fresh Market Price Forecast Agent（FMPA）**，以消費者當下取得的個別店家價格為預測錨點，結合公開市場歷史價格資料與領域分析工具，提供未來 7 天及 14 天的價格變化參考。

研究關注的核心問題是：公開市場均價不必然等於個別零售店的實際價格，而消費者需要的是以「今天看到的店價」為起點，理解未來短期價格可能如何變動。系統因此整合自然語言查詢、工具調用、價格預測與結果解釋，作為消費者價格判斷的輔助。

## Three Core Innovations｜三大核心創新

### 1. Current Price-Anchored Forecasting — 現價錨定式價格預測

以消費者當下取得的個別店家價格作為預測基準，結合公開市場歷史價格資料，估計未來 7 天與 14 天的相對價格變化。

系統設計兩種預測模式：

- **A 模式｜現價錨定：** 以當下店價為基準，套用模型估計的相對變化。
- **B 模式｜週價動量調整：** 在現價錨定的基礎上，加入固定規則的動量微調。

此設計希望讓預測結果更貼近消費者實際查價情境，而非直接將公開市場均價當作個別店家的真實價格。

### 2. Calendar-Based Temporal Analysis — 固定日曆天之時間序列分析

採用固定 **7 天與 14 天日曆日**作為預測區間，分別使用不同模型進行分析：

- **7 天：** Random Forest（RF）。
- **14 天：** HistGradientBoosting（HGB）。

實驗以方向 macro-F1 與相對變化 MAE 作為評估指標，並與「不變價基線」及「動量基線」比較，檢驗模型、輸入特徵與預測模式是否帶來實際增益。

> 研究結果須如實呈現：目前分析中，模型方向 macro-F1 未勝動量基線，相對變化 MAE 亦未勝持平不變價基線；因此不主張模型已優於簡單基線。

### 3. Domain-Aware Agentic Interaction — 領域知識驅動的智慧代理互動

整合大型語言模型（LLM）、Model Context Protocol（MCP）工具與價格預測引擎，讓使用者能以自然語言提出農產品價格查詢。

系統明確劃分工作責任：

- **LLM：** 理解使用者意圖、選擇工具、整理與解釋結果。
- **領域工具與預測引擎：** 執行資料檢索、領域規則檢查及數值運算。
- **安全與錯誤處理：** 資料不足、信心不足或工具失敗時，要求補充資訊或明確回報，不由 LLM 自行猜測價格。

## 核心研究價值

從傳統公開市場均價查詢（**Public Market Price Lookup**），邁向以消費者當下店價為基準，結合時間序列預測與智慧代理互動的價格決策輔助系統（**Current Price-Anchored, Agentic Price Decision Support**）。

## 研究問題

- **RQ1：** 評估固定 7 天與 14 天預測的效果。
- **RQ2：** 檢驗 A／B 模式及其輸入設計是否帶來增益。
- **RQ3：** 評估自然語言與工具整合所提供的低負擔查詢可行性。

## 系統架構概念

系統主要包含五個模組：

1. **使用者入口：** 接收自然語言價格查詢。
2. **MCP 工具：** 提供工具調用與系統整合介面。
3. **Oracle 主機 API：** 存取所需資料與服務。
4. **ForecastEngine：** 執行 RF／HGB 預測及模式規則。
5. **公開歷史資料：** 支援模型訓練、分析與評估。

整體流程：**Input → Check → AI／Analytics → Decision → Output**。

## 實驗資料與評估

目前研究解析所述的實驗資料為臺中市 13 個公有市場歷史資料：

| 預測區間 | 模型 | 樣本數 |
|---|---|---:|
| 7 天 | Random Forest | 2,085 |
| 14 天 | HistGradientBoosting | 1,859 |

評估指標：

- **方向 macro-F1：** 評估價格變動方向判斷。
- **相對變化 MAE：** 評估相對價格變化幅度的預測誤差。

比較基線：不變價基線、動量基線。

## 限制與未來工作

公開市場均價不等同於個別店家的實際成交價；因此目前結果應定位為價格變化參考，而非特定店家的價格保證。後續重要工作是蒐集到期的同店實際價格，進行預測值與真實店價的配對驗證，並進一步檢驗不同資料來源及預測設定的適用範圍。

## 技術與研究誠信原則

1. LLM 負責意圖理解、工具選擇與結果說明，不自行推算或猜測菜價。
2. 嚴格檢查時間資訊與標籤成熟度，降低資料洩漏風險。
3. 同時報告模型與簡單基線的比較結果，包含未優於基線的負向結果。
4. 清楚揭露 AI 工具在研究、程式與文稿輔助中的使用範圍。
